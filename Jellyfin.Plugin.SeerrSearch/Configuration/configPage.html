Seerr Search

Shows Seerr results under the Jellyfin search, with a Request button. Each request is created as the Seerr account linked to the signed-in Jellyfin user.

Quick start

Two fields are enough: the Seerr address (found automatically when possible) and the Seerr API key. Then click “Save and test”. Everything under “Advanced settings” is optional.

The address the Jellyfin SERVER uses to reach Seerr. Same Docker network: the container name, http://seerr:5055. Otherwise the IP address of the machine that runs Seerr: http://192.168.1.10:5055. Never localhost (inside Docker, that is the Jellyfin container itself).
Seerr → Settings → General → API Key. It stays on the server and is never sent to the users' browsers.
A key is saved. Leave this field empty to keep it.

Advanced settings (all optional)

“Open in Seerr” and automatic sign-in

The address your users type in THEIR browser to open Seerr. Leave it empty to use the Application URL set in Seerr (Settings → General), if there is one. Used by the "Open in Seerr" link and by the automatic sign-in.
The address your users type in their browser to open Jellyfin. With a public Seerr URL, tapping a card opens Seerr already signed in (Quick Connect, no password). It works when: the proxy in front of Seerr forwards /SeerrSearch/ to Jellyfin (detected automatically, preferred); or Jellyfin and Seerr are on the same host with different ports (http://192.168.1.10:8096 and http://192.168.1.10:5055); or they are subdomains of one domain (jellyfin.example.com and seerr.example.com). Quick Connect must be enabled in Jellyfin.
Normally detected by itself. Tick it only if the test says it cannot reach Seerr's public address from this server (some networks do not loop back to their own public address) while your proxy does forward /SeerrSearch/ to Jellyfin.
With automatic sign-in set up, the link is always shown. Without it, the link opens Seerr signed out.

Users who have no Seerr account

A Jellyfin user only gets Seerr results if their account exists in Seerr. Use the import button below to create the missing accounts.
Replaces the built-in message shown to users without a Seerr account. Plain text, 300 characters at most.

Technical

Only tick this if another plugin already takes care of the injection.

Connection and users

A user only sees Seerr results if their Jellyfin account is imported into Seerr. The import creates the missing accounts with Seerr's default permissions (the same as Seerr → Users → Import from Jellyfin).
