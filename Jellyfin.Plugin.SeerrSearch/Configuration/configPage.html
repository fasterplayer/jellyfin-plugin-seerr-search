Seerr Search

Ajoute les résultats de Seerr sous la recherche Jellyfin. Chaque demande est créée au nom du compte Seerr lié à l'utilisateur Jellyfin connecté.

Par exemple http://seerr:5055 si les deux conteneurs partagent un réseau Docker.
Seerr → Paramètres → Général → Clé API. Elle reste sur le serveur et n'est jamais envoyée au navigateur.
Sert au lien « Ouvrir dans Seerr » de la fiche, par exemple https://seerr.mondomaine.ca.
Avec une URL publique de Seerr, un appui sur une carte ouvre Seerr déjà connecté (Quick Connect, sans mot de passe). Deux façons : soit le proxy devant Seerr relaie /SeerrSearch/ vers Jellyfin (détecté tout seul, préférable), soit Jellyfin et Seerr partagent un domaine parent (jellyfin.mondomaine.ca et seerr.mondomaine.ca) et cette URL est remplie. Le Quick Connect doit être activé dans Jellyfin.
Code TMDB, par exemple fr, fr-CA ou en.
Ils apparaissent déjà dans les résultats Jellyfin juste au-dessus.
Seerr applique quand même ses propres permissions par utilisateur.
Avec la connexion automatique configurée, le lien est toujours affiché. Sans elle, il ouvre Seerr déconnecté.
À cocher seulement si un autre plugin s'occupe déjà de l'injection.

Connexion et utilisateurs

Un utilisateur ne voit les résultats Seerr que si son compte Jellyfin est importé dans Seerr. L'import est aussi faisable depuis Seerr → Utilisateurs → Importer depuis Jellyfin.
