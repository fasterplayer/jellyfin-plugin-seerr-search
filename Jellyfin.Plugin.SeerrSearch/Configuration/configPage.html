Seerr Search

Shows Seerr results under the Jellyfin search, with a Request button. Each request is created as the Seerr account linked to the signed-in Jellyfin user.

For example http://seerr:5055 when both containers share a Docker network, or http://192.168.1.10:5055. Only http and https are accepted.
Seerr → Settings → General → API Key. It stays on the server and is never sent to the users' browsers.

Used by the "Open in Seerr" link, for example https://seerr.example.com.
With a public Seerr URL, tapping a card opens Seerr already signed in (Quick Connect, no password). Two ways: either the proxy in front of Seerr forwards /SeerrSearch/ to Jellyfin (detected automatically, preferred), or Jellyfin and Seerr share a parent domain (jellyfin.example.com and seerr.example.com) and this URL is filled in. Quick Connect must be enabled in Jellyfin.

Connection and users

A user only sees Seerr results if their Jellyfin account is imported into Seerr. The import creates the missing accounts with Seerr's default permissions (the same as Seerr → Users → Import from Jellyfin).
