# Security policy

If you find a security problem in Seerr Search, please do **not** open a public issue. Use GitHub's
private vulnerability reporting (Security tab → "Report a vulnerability") on this repository, or contact
the maintainer through the address on their GitHub profile.

Please include the plugin version, the Jellyfin version, and the steps to reproduce.

The design and the protections in place are described in the "Security" section of the
[README](README.md).

Signalez un problème de sécurité par le signalement privé de vulnérabilité de GitHub (onglet Security),
pas dans une issue publique.
